# Картинка: лазерная гравировка фото и рисунков

Картинка (PNG, JPG, BMP…) выжигается строка за строкой: светлое — слабее или не выжигается, тёмное — сильнее.
Оттенки — мощностью, скоростью, дизерингом (точками) или порогом (чёрно-белое).

---

## Как добавить

1. Профиль лазера и лазерный инструмент — как в [«Лазер»](laser-vector.md#перед-началом).
2. **«+ Картинка»** → файл. Картинка встанет левым нижним углом в X, Y.
3. «Заменить…» — другая картинка с теми же настройками.

## Поля

| Поле | Что значит | С чего начать |
|---|---|---|
| **X, Y** | Левый и нижний край в чертеже, мм | 0, 0 |
| **Ширина, мм** | Ширина гравировки; высота — по пропорциям картинки | — |
| **Шаг строк, мм** | Расстояние между строками и размер точки: 0,1 мм ≈ 254 dpi | 0,1 (пятно 0,1–0,15) |
| **Режим** | **Оттенки серого** — мощность по яркости. **Дизеринг** — чёрно-белые точки, создающие впечатление серого (хорош для фото на дереве). **Чёрно-белое (порог)** — логотипы, текст, штриховые рисунки | Дизеринг для фото |
| **Мощность мин. / макс., %** | Мощность для самых светлых выжигаемых и для самых тёмных точек | 0 / 40–60 |
| **Скорость, мм/мин** | Скорость строк | 1500–2500 |
| **Перебег, мм** | Заезд за края: там лазер разгоняется с выключенным лучем, иначе края темнее | 2–5 |
| **Инверсия** | Выжигать светлое вместо тёмного (негатив, гравировка по тёмному материалу) | — |
| **В обе стороны** | Строки туда и обратно — вдвое быстрее, но при люфте строки сдвигаются | Вкл. |
| **Оттенки** | **Мощностью** — при постоянной скорости. **Скоростью** — мощность постоянная (макс.), тёмное идёт медленнее: для диодных лазеров, которые на малой мощности не жгут, а потом сразу сильно | Мощностью |
| **Скорость мин., мм/мин** | Только для оттенков скоростью: скорость самых тёмных точек | 300–600 |

## Как подготовить картинку

- Обрежьте лишнее, поднимите контраст, переведите в оттенки серого.
- Разрешение не больше нужного: ширина 80 мм при шаге 0,1 мм — 800 точек. Большая картинка только замедлит расчёт.
- Фон — чисто белый: даже светло-серый фон будет слегка выжжен (или «Мощность мин.» = 0).
- Для фото на дереве часто лучше всего **дизеринг**: светлое дерево и тёмные точки.

## Пошагово: фото на фанере

1. Подготовленное фото 800 × 600 точек.
2. «+ Картинка», ширина **80**, шаг строк **0,1**, **Дизеринг**, мощность макс. **50 %** (5 Вт), скорость **2000**.
3. Сначала — маленький тест (ширина 20 мм) на обрезке той же фанеры, затем — вся картинка.

## Если что-то не так

| Признак | Что делать |
|---|---|
| Слишком тёмно / прогорает | Меньше «Мощность макс.» или больше скорость |
| Светлые места не видны | «Мощность мин.» чуть больше; оттенки «скоростью» |
| Строки сдвинуты «ёлочкой» | Люфт: выключите «В обе стороны» или снизьте скорость, подтяните ремни/гайки |
| Края темнее середины | Больше «Перебег» |
| «Слишком большое разрешение» | Увеличьте «Шаг строк» или уменьшите ширину |
