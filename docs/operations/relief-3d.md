# Рельеф 3D: поверхность из картинки или STL, дообработка остатков

Фреза обрабатывает объёмную поверхность: из **картинки** (яркость → глубина: барельеф, логотип, текстура) или из
**3D-модели STL**. Расчёт учитывает форму фрезы («падающая фреза»), поэтому она не врезается в соседние склоны.
Черновые проходы снимают лишнее по уровням, чистовые — строками и/или по уровням Z (waterline). **Дообработка**
меньшей фрезой проходит только там, где по результату симуляции над моделью остался материал.

## Как добавить

- **Из картинки**: «+ Рельеф (картинка)» → файл PNG/JPG/BMP (тёмное — глубже; «Инверсия» — наоборот).
- **Из STL**: «STL» на панели или «+ Рельеф (STL)» → файл модели. Модель ложится верхом на «Начало (Z)».

Затем инструмент: «Рельеф 3D: Сферическая Ø3,175 (R1,6)» или «Ø2 (R1)» — сферическая фреза даёт гладкую поверхность.

## Поля

| Поле | Что значит | С чего начать |
|---|---|---|
| **Источник / Заменить…** | Картинка или STL; «Заменить…» — другой файл с теми же настройками | — |
| **X, Y** | Левый нижний угол рельефа в чертеже | 0, 0 |
| **Ширина, мм** | Ширина рельефа; длина подстроится по пропорциям | — |
| **Глубина, мм** | Глубина самых тёмных мест (картинка) или высота модели (STL) | 2–5 |
| **Начало (Z), мм** | Верх рельефа: 0 — верх заготовки | 0 |
| **Инверсия** | Картинка: светлое — глубже | — |
| **Шаг сетки, мм** | Точность модели: меньше — точнее, но дольше расчёт | 0,2 |
| **Шаг строк, мм** | Расстояние между чистовыми строками: 10–20 % диаметра сферической фрезы | 0,3 для Ø3,175 |
| **Направление строк** | Вдоль X или вдоль Y | Вдоль X |
| **Черновая, припуск** | Сначала снять материал уровнями по «Шагу по глубине» инструмента, оставив припуск на чистовую | Вкл., 0,3 |
| **Чистовая** | **Строками** (пологие места), **по уровням** (waterline, крутые стенки) или **строками + по уровням** | Строками |
| **Шаг уровней Z, мм** | Расстояние между уровнями waterline | 0,2 |
| **Фрезерование уровней** | Попутное / встречное для waterline | Попутное |
| **Уровни круче, °** | Waterline только там, где склон круче угла; пологое — строкам. 0 — везде | 35 |
| **Только внутри контуров** | Обрабатывать только внутри назначенных замкнутых контуров | — |
| **Дообработка остатков** | Обработать только то, что оставили операции перед этой (см. ниже) | — |
| **Допуск остатков, мм** | Остаток тоньше не трогать | 0,05 |

## Черновая и чистовая

- Глубина больше «Шага по глубине» без черновой — PathForge предупредит: фреза пошла бы на всю глубину сразу.
- Черновая и чистовая идут одной фрезой. Если хочется черновую **концевой** фрезой побольше, сделайте её отдельной
  операцией рельефа (её чистовой проход будет грубым — не страшно), а следом — рельеф сферической фрезой
  с «Дообработкой остатков»: она пройдёт только там, где концевая оставила материал.
- Плоская фреза на чистовой оставит ступеньки — PathForge предупредит.

## Дообработка остатков меньшей фрезой

Крупная сферическая фреза не помещается в узкие впадины, острые углы и мелкие детали модели. Чтобы не гонять мелкую
фрезу по всей поверхности:

1. Сделайте рельеф крупной фрезой (черновая + чистовая).
2. Вкладка **«3D-симуляция»** → **«Сравнить с моделью»**: синие места — там остался материал.
3. Нажмите **«+ Дообработка остатков»**: появится копия рельефа с **самой крупной из меньших** сферических фрез
   или гравёров проекта и включённой «Дообработкой остатков». (Можно и вручную: копия операции + флажок.)
4. PathForge **симулирует все операции перед ней**, кладёт мелкую фрезу на получившийся остаток и оставляет только те
   строки и уровни, где фреза действительно снимет больше «Допуска остатков». Черновые уровни (если включены)
   ограничиваются так же — глубокую нетронутую впадину мелкая фреза пройдёт по шагам, а не за один раз.
5. «3D-симуляция» → «Пересчитать» → «Сравнить с моделью»: синего должно стать заметно меньше.

Если остатков нет — «остатков нет — предыдущие операции уже обработали модель с допуском …», операция пропускается.
Если перед дообработкой нет фрезерных операций — она обрабатывает всю поверхность.

## Пошагово: барельеф из картинки

1. Картинка в оттенках серого, 500–1000 точек по ширине (больше не нужно: шаг сетки 0,2 мм).
2. «+ Рельеф (картинка)», ширина **80**, глубина **3**, шаг сетки **0,2**.
3. Инструмент «Сферическая Ø3,175», черновая с припуском **0,3**, чистовая **строками**, шаг строк **0,3**.
4. «+ Дообработка остатков» → со «Сферической Ø2» (добавьте пресет, если нет).
5. «3D-симуляция» → проверить, «Сравнить с моделью».

## Если что-то не так

| Признак | Что делать |
|---|---|
| «Слишком мелкая сетка» | Увеличьте «Шаг сетки» или уменьшите размер |
| Полосы и гребешки | Меньше «Шаг строк»; строки поперёк основных склонов; чистовая «строками + по уровням» |
| Стенки ступенчатые | Waterline («по уровням») с шагом 0,1–0,2 на крутых местах |
| Мелкие детали «размыты» | Фреза крупная: дообработка меньшей фрезой |
| Обработка дольше, чем ожидалось | Ограничьте область «Только внутри контуров», уменьшите шаг только на чистовой |
