# Текст: надписи любым шрифтом

Вкладка **«Текст»** превращает надпись любым установленным в Windows шрифтом в контуры. С ними работают все
операции: контур, карман, V-карвинг, лазер. Поддерживаются шрифты TrueType и OpenType (включая CFF),
**вариативные** шрифты (насыщенность, ширина и другие оси), кернинг и **текст по дуге**.

---

## Как добавить

1. Вкладка **«Текст»** → **«+ Текст»**.
2. Напечатайте надпись (можно в несколько строк), выберите шрифт — буквы появятся на чертеже и сразу будут выделены.
3. Добавьте операцию: **«+ V-карвинг»** (кнопка прямо на вкладке), «+ Контур» «По линии», «+ Карман» или «+ Лазер».

Если потом поменять текст или шрифт, операции получат новые буквы сами.

## Поля

| Поле | Что значит |
|---|---|
| **Текст** | Надпись; Enter — новая строка |
| **Шрифт** | Любой установленный шрифт; начните печатать название, чтобы найти |
| **Высота букв, мм** | Высота заглавных букв |
| **X, мм / Y, мм** | Начало базовой линии первой строки (в координатах чертежа) |
| **Выравнивание** | Влево / по центру / вправо относительно точки X |
| **Между буквами, мм** | Дополнительный зазор между буквами (может быть отрицательным) |
| **Между строками, ×** | Межстрочный интервал в долях высоты букв |
| **Кернинг** | Пары вроде «AV», «To» ставятся ближе — как в типографике |
| **Зеркально** | Зеркальная надпись — для нижнего слоя платы или штампа |
| **Слой** | Слой чертежа, в который попадут буквы |
| **По дуге, радиус мм** | 0 — по прямой. **Плюс** — по верху окружности, буквы наружу (центр на радиус ниже точки X, Y). **Минус** — по низу, буквы читаются прямо |
| **Начертание / оси** | Для вариативного шрифта (например, Bahnschrift): готовые начертания и ползунки осей — насыщенность (wght), ширина (wdth) |

Кнопки: **«Удалить»** — убрать надпись вместе с её контурами, **«Выделить буквы»** — выделить контуры надписи на
чертеже (чтобы назначить их другой операции).

## Круглая печать

1. Текст 1: «ВЕРХНЯЯ НАДПИСЬ», выравнивание **по центру**, «По дуге» **+30**.
2. Текст 2: «нижняя надпись», тот же X, по центру, «По дуге» **−30**, а Y — на **60 мм меньше** (2 × радиус):
   у плюса центр окружности на радиус ниже точки, у минуса — на радиус выше, так центры совпадут.
3. Кольцо: окружность из чертежа или контур.
4. Для штампа включите «Зеркально».

## Советы

- Для фрезы выбирайте шрифты без очень тонких штрихов: штрих тоньше фрезы она не вырежет (V-карвинг — справится).
- Для лазера подходят любые шрифты; для заливки — «+ Лазер», режим «Заливка».
- Буквы с «дырками» (О, А, В) — карман и V-карвинг сами учтут внутренние контуры как острова.
- В раскладке деталей детали с текстом не поворачиваются (надпись осталась бы редактируемой).

## Если что-то не так

| Признак | Что делать |
|---|---|
| Шрифта нет в списке | Он не установлен в Windows или это не TrueType/OpenType (растровые шрифты не поддерживаются) |
| Буквы налезают друг на друга | «Между буквами» больше; рукописные шрифты специально соединяют буквы |
| Текст по дуге «вверх ногами» | Поменяйте знак радиуса |
| Операция не видит новые буквы | Операции, которым назначены буквы, обновляются сами; если назначали вручную другой набор — «Выделить буквы» → «Назначить выделенные» |
