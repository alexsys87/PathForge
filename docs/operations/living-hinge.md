# Гибкий шарнир (living hinge)

Ряды прорезей в шахматном порядке: перемычки между прорезями скручиваются, и фанера 3 мм в этой области гнётся,
как ткань. Так делают коробки со скруглёнными углами из одной стенки, обложки блокнотов, браслеты, абажуры.

---

## Узор

```
----- --------- --------- -----    ← нечётная линия: перемычки напротив середины прорезей, крайние — до края
 --------- --------- ---------      ← чётная линия: перемычки на обоих концах
----- --------- --------- -----
 --------- --------- ---------
```

*Прорези вдоль X; «вдоль Y» — тот же узор, повёрнутый на 90°.*

- Прорези одной линии разделены **перемычками**; у соседних линий перемычки сдвинуты на половину шага — посередине
  прорезей.
- Длина прорезей подгоняется так, чтобы в область уложилось целое число прорезей с перемычками на концах.
- Линии идут с **шагом** по ширине области, по центру; прорези режутся линия за линией, змейкой.

## Как добавить

1. Нарисуйте деталь (стенку коробки) и прямоугольник зоны изгиба — или просто знайте её координаты.
2. Вкладка «Операции» → раскройте **«Гибкий шарнир (living hinge)»**. Выделите прямоугольник зоны → **«По выделению»**
   (или впишите X, Y, ширину и высоту).
3. **«+ Гибкий шарнир»**: прорези появятся на слое «Living hinge», операция «Гибкий шарнир» — **перед** первой лазерной
   резкой по линии, с её мощностью, скоростью и проходами (панель режется последней, пока шарнир держится в листе).
4. Прямоугольник зоны изгиба не режьте: уберите его из операции резки или скройте его слой.

## Поля

| Поле | Что значит | Фанера 3 мм |
|---|---|---|
| **X, Y, ширина, высота** | Область шарнира на чертеже | Зона изгиба |
| **Прорези** | **Вдоль Y** — панель гнётся вокруг вертикальной оси (стенка коробки), **вдоль X** — вокруг горизонтальной | Вдоль оси изгиба |
| **Длина, мм** | Длина прорези: длиннее — мягче | 15–25 |
| **Перемычка, мм** | Целый материал между прорезями одной линии: короче — мягче, но ломче | 2–4 |
| **Шаг линий, мм** | Расстояние между линиями прорезей: меньше — гнётся круче, но ломче | 1,2–2 |
| **До края** | Каждая вторая линия прорезается до края области — гибче, если шарнир идёт через всю панель от края до края. Выключите, если зона внутри панели | Вкл., если зона от края до края |

Длина зоны изгиба для угла коробки: дуга радиуса R на 90° — это `π × R / 2` (R = 15 мм → ≈ 24 мм), плюс по 2–3 мм
с каждой стороны.

## Советы

- Сначала вырежьте **пробную полоску** 30 × 80 мм с шарниром из той же фанеры. Ломается — увеличьте шаг линий или
  длину прорезей; не гнётся — уменьшите шаг.
- Гните поперёк волокон наружного слоя фанеры: вдоль волокон шарнир ломается.
- Режим — как для сквозной резки; прорези должны прорезаться насквозь, иначе шарнир не согнётся.
- Тонкие полоски между линиями нагреваются: если они обугливаются, включите обдув и увеличьте скорость (больше
  проходов вместо медленного одного).
