# Коробки и приборные панели

Всё, что нужно для корпуса самоделки: коробка из фанеры или акрила с соединением «шип-паз», вырезы под разъёмы
и органы управления, шкалы вокруг ручек, фаски и потайные отверстия, а также правка чертежа прямо в PathForge.

Почти всё — на вкладке **«Конструктор»**; операции «Фаска» и «Отверстия по спирали» — на вкладке «Операции».

## 1. Выделение и правка чертежа

**Выделение рамкой** на 2D-чертеже: зажмите **Shift** и протяните мышью.

- **Вправо** (сплошная рамка) — выделяются контуры, целиком попавшие в рамку.
- **Влево** (пунктирная рамка) — выделяются все контуры, которых рамка коснулась.
- **Ctrl+Shift** — добавить к уже выделенному; без Ctrl выделение заменяется.

Клик с Shift или Ctrl, как и раньше, добавляет или убирает один контур. **Del** на чертеже — удалить выделенное.

**«Конструктор» → «Изменить выделенное»:**

| Действие | Что делает |
|---|---|
| **Сдвинуть** | На X / Y мм. Текст, выделенный целиком, едет вместе с буквами и остаётся редактируемым |
| **Повернуть** | На угол (против часовой, минус — по часовой) вокруг центра выделения |
| **Масштаб** | Во столько раз, одинаково по X и Y, вокруг центра выделения |
| **Массив** | Копии сеткой: столбцы × ряды (вместе с исходным) с шагом X / Y |
| **По кругу** | Копии по окружности вокруг центра: штук (вместе с исходным) и угол (360 — равномерно по кругу). «Поворачивать копии» — копии поворачиваются вместе с кругом. Центр удобно взять кнопкой «По выделению» с выделенной окружности |
| **Удалить** | Убирает контуры из чертежа и из операций |

- Копии сразу попадают во все операции, где был исходный контур.
- Повёрнутые, отмасштабированные и скопированные буквы текста становятся обычными контурами (текст больше не
  редактируется — его можно удалить и добавить заново).
- Любое действие отменяется **Ctrl+Z**.

## 2. Коробка с шипами

**«Конструктор» → «Коробка с шипами»**:

| Поле | Что значит |
|---|---|
| **Ш × Г × В** | Ширина (X), глубина (Y), высота |
| **Внутренние размеры** | Размеры внутри коробки (что в неё должно поместиться); выключено — снаружи |
| **Толщина** | Толщина листа — **измерьте**: «фанера 3 мм» бывает 2,7–3,2 |
| **Шип** | Желаемая ширина шипа; подгоняется, чтобы на каждой кромке было нечётное число шипов (обычно 2–4 толщины) |
| **Крышка** | **Без крышки**; **накладная** — пластина сверху и вкладыш под ней (приклеить), чтобы крышка не съезжала; **сдвижная** — едет в пазах боковых и задней стенок, передняя стенка ниже на две толщины |
| **Посадка** | Зазор в каждом соединении: плюс — свободно (под клей), минус — натяг |
| **Зазор** | Расстояние между деталями на листе (для фрезы — больше её диаметра) |

**«+ Коробка»** раскладывает детали справа от чертежа рядами по ширине поля станка (слой «Коробка») и добавляет
операции:

- **профиль лазера** — резка по линии с обдувом, «Ширина реза: детали в размер» (ширина = пятно лазера);
- **фрезер** — «Контур» снаружи самой крупной концевой фрезой до Ø3,2, глубина = толщина + 0,2 мм, **подрезка
  углов dogbone** (иначе шипы не войдут в пазы, см. раздел 3).

Сдвижная крышка: пазы на внутренней стороне стенок (слой «Коробка: пазы крышки») глубиной в полтолщины
выбираются отдельной операцией перед вырезкой — фрезой (карман) или лазером (заливка; число проходов подберите
так, чтобы получилась половина толщины). Кладите стенки **внутренней стороной вверх** — чертёж нарисован с неё.

Советы:

- Сначала вырежьте **пробный угол** (две небольшие стенки) и подберите «Посадку»: туго — плюс 0,05…0,1, болтается —
  минус.
- Фанера неровная по толщине: шипы на одной кромке могут входить туже, чем на другой. Это нормально.
- Детали после вырезки фрезой держите скотчем или саморезами по краям листа: перемычки на шипах мешали бы сборке.

## 3. Подрезка углов (dogbone / T-bone)

Круглая фреза не может прорезать острый внутренний угол: в нём остаётся скругление радиусом фрезы, и
квадратный шип в такой паз не входит. В операции **«Контур»** поле **«Подрезка углов»**:

- **Dogbone** — фреза заходит в угол по биссектрисе и касается точки угла: в углу получается круглое «ухо».
- **T-bone** — фреза заходит в угол вдоль более длинной стороны: ухо спрятано в этой стороне (аккуратнее снаружи).

Подрезаются только углы, куда фреза иначе не достаёт: углы отверстий и пазов при стороне «Внутри», внутренние
углы вырезов детали (пазы между шипами) при стороне «Снаружи». Внешние углы фреза и так огибает.

## 4. Вырезы для панели

**«Конструктор» → «Вырезы для панели»**: выберите вырез, поправьте размеры, задайте центр (или «По выделению» —
центр выделенного контура) и поворот → **«+ Вырез»**. Контуры появятся на слое «Вырезы» выделенными — добавьте
операцию: «+ Контур» внутри (с подрезкой углов для прямоугольных), «+ Отверстия по спирали» для круглых или
лазер.

| Вырез | Что получается |
|---|---|
| Круглое отверстие, прямоугольник со скруглением | По размерам |
| Отверстие с лыской | Круг с плоским срезом сверху (чтобы деталь не проворачивалась): диаметр и размер «по лыске» |
| Отверстия Ø7 / 9 / 12 / 16 / 19 / 22 | Тумблеры, потенциометры, кнопки (+0,3 мм на посадку; лыску можно добавить) |
| D-Sub DB9 / DB15 / DB25 | Окно «D» со скошенными боками и два крепёжных отверстия Ø3,2 (25 / 33,3 / 47 мм) |
| USB-A / USB-B / USB-C | Прямоугольные окна со скруглением |
| XLR (Neutrik D) | Ø24 и два крепёжных отверстия по диагонали 19 × 24 мм |
| Разъём питания 5,5 мм | Ø11 (для гнёзд на гайке; поправьте под своё) |
| Дисплеи LCD 1602 / 2004, OLED 0,96″ / 1,3″ | Окно под рамку экрана и четыре крепёжных отверстия |
| Вентиляция: отверстия / щели / соты | Решётка в прямоугольнике заданного размера: только целые отверстия |
| Крепёжные отверстия по углам | Четыре отверстия с отступом от углов панели (центр и размер панели — «По выделению» с контура панели) |

> Размеры типовые. У дисплеев и разъёмов разных производителей они отличаются — **сверьте со своей деталью**
> штангенциркулем и поправьте поля.

## 5. Шкала для ручки

**«Конструктор» → «Шкала для ручки»**: выделите отверстие под вал → «По выделению», задайте радиус (чуть больше
ручки), начало и охват (потенциометр: 225° и 270°), число делений, какие риски длинные, цифры → **«+ Шкала»**.

- **Толщина линий 0** — риски и цифры линиями: гравируйте «Контуром» по линии гравёром или лазером.
- **Толщина больше 0** — замкнутые контуры такой ширины: для V-карвинга или кармана.
- Переключатель на 6 положений: делений 5, длинная каждая 1, цифры 1…6, охват по углу поворота переключателя.

## 6. Фаска V-фрезой

**«+ Фаска»** (вкладка «Операции») по выделенным замкнутым контурам:

- **Снаружи** — скос кромки панели;
- **Внутри** — край отверстия: **потай** под винт с потайной головкой. Ширина = (Ø головки − Ø отверстия) / 2,
  фреза 90°.

Глубина считается сама: ширина / tg(половины угла фрезы) — у 90° она равна ширине; проходы по шагу инструмента.
Кончик фрезы идёт на половину своей ширины от кромки. Делайте фаску до вырезки детали, пока заготовка закреплена.

## 7. Отверстия по спирали и цековка

**«+ Отверстия по спирали»** по выделенным окружностям: фреза опускается по спирали вдоль стенки — без
вертикального врезания. Отверстия больше двух диаметров фрезы выбираются кольцами от центра наружу, последнее
кольцо — чистовое. Быстрее и круглее кармана.

| Поле | Что значит |
|---|---|
| **Ø отверстия** | 0 — диаметр каждой окружности; иначе один диаметр для всех |
| **Ø цековки, глубина** | Цековка под головку винта фрезеруется первой: M3 — Ø6,5 × 3,3; M4 — Ø8 × 4,3; M5 — Ø10 × 5,3 |
| **Угол спирали** | Наклон: за виток фреза опускается на 2πR·tg(угла), но не больше шага инструмента (2–5° для 3018) |

## 8. Пример: передняя панель

1. Нарисуйте прямоугольник панели (или импортируйте) → выделите его.
2. «Вырезы для панели» → «Крепёжные отверстия по углам» → «По выделению», размеры панели → «+ Вырез».
3. Вырезы под дисплей, кнопки, разъёмы: центр — числами или «По выделению» с нарисованных меток.
4. Отверстие потенциометра → «Шкала для ручки» → «По выделению» → «+ Шкала».
5. Операции: шкала — гравёр по линии; круглые отверстия — «Отверстия по спирали»; окна — «Контур» внутри с
   подрезкой углов; кромка — «Фаска» снаружи; панель — «Контур» снаружи последним.
